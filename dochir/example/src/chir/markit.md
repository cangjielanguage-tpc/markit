## CHIR Package Guide

This package mirrors the public CHIR API surface used by dochir during documentation extraction.

| Area | Purpose |
| --- | --- |
| Types | Represent CHIR type nodes and user-defined definitions. |
| Values | Represent global values, parameters, literals, and expressions. |
| Builder | Creates CHIR expressions and inserts them into blocks. |
